# 农场业务重构与验收记录

日期：2026-11-10。场景：当前 Chicken 项目，Place ID `134743372234687`。

## 本轮结果

保留 `ServerRoot → ServerGameManager` 和 `ClientRoot → ClientGameManager` 入口，原约 792 行的农场主管理器收敛为初始化、动作分发、更新调度和资源清理。子模块分别负责产蛋孵化、动物行为与生命值、电击、库存与交货、升级、餐厅和场景表现。

`ServerGameInfo` 持有共享农场会话状态；`ServerFarmTypes` 定义服务端状态与子系统上下文。客户端由 `ClientGameInfo` 集中读取 `Farm*` Attributes，通过 `ClientMsg` 驱动 HUD。Attributes 仅为同步投影。

`FarmConfig` 集中维护当前玩法参数；`RoastChickenCatalog.creatures` 为正式物种列表，不再混用数字索引和配置字段。旧根目录的 Catalog 模块保留重定向，项目内调用均指向 Shared。`NetMsg` 校验现有六种动作，通过正式 RemoteEvents 节点通信。

UI 由 `UIManager` 克隆正式模板。HUD、模态遮罩、四类 Billboard 和公共静态禁放参考模板已在 Studio Edit 预置；业务代码不再运行时创建 GUI。动态词条集中在 `GameTexts`，业务适配器使用 Core 现有翻译接口并在销毁时注销。普通 HUD 使用固定 1920×1080 画布居中等比缩放；旧动态区域引擎已移除。

`LifecycleTool` 为业务层新增工具，管理连接、协程、Tween 与临时实例；界面、玩家、子管理器及分析上报具备释放入口。退出保存先于玩家资料移除，异步玩家加载会检查会话仍有效。没有改动原存档格式、版本号、DataStore 名称或服务开关。
