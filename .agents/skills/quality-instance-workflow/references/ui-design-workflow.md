# 优质 UI 界面设计流程 (Quality UI Design Workflow)

本流程整合 Roqer 的 `roblox-ui-design` 体系与高品质 Roblox 项目设计准则，用于构建专业级、高完成度且具备多端自适应能力的界面资产。

---

## 一、三大主题风格体系 (Theme Routing)

在开始任何优质 UI 创建前，必须首先明确界面的设计语言与主题：

1. **SIM 主题（卡通圆角卡片风）**：
   - 特征：纯白/浅色底板、大圆角（`UICorner` 12~16 px）、柔和弥散阴影、高饱和度鲜艳描边；
   - 适用：模拟器、放置点击、养成、休闲合家欢游戏。
2. **MODERN STUDS 主题（现代积木凸点风 - 默认推荐）**：
   - 特征：微圆角带外唇、强对比度边框（`UIStroke`）、经典的积木 Stud 质感平铺与金属卡扣边缘；
   - 适用：经典 Roblox 风格、对战、竞技、工坊、硬核玩法。
3. **CLASSIC STUDS 主题（经典复古方块叠层风）**：
   - 特征：纯方角斜角浮雕、像素感厚底板、多层矩形堆叠；
   - 适用：怀旧、老式经典 Roblox 界面重现。

## 二、14 类语义布局模板矩阵 (Semantic Layouts)

禁止凭空随意摆放 Frame，必须根据信息架构选择对标的标准布局模板：

| 布局模版分类 | 对应模版名称 | 典型应用场景 | 关键设计契约 |
|---|---|---|---|
| **常驻玩法 HUD** | `hud-zone-system` | 血条、经验、货币条、快捷操作区 | 避让屏幕边缘安全区，常驻展示不遮挡视线 |
| **持久侧边栏** | `vertical-navigation-sidebar` | 左侧/右侧功能导航入口 | 竖向弹性列表，带小红点与激活状态动效 |
| **商业化与商城** | `shop-grid` | 道具商城、通行证、限时礼包 | 卡片网格展示、角标、打折划线价、购买弹窗联动 |
| **背包与存储** | `grid-inventory` | 装备、宠物、背包、物品栏 | 网格多页滚动、品质色边框、长按浮动详情框 |
| **全屏登录/选关** | `fullscreen-landing` | 标题画面、选图、角色选择 | 纯黑/半透全屏遮罩、居中 Logo、主操作按钮 |
| **选择与对比** | `select-screen` | 阵营选择、职业挑选、属性对比 | 左右分栏对比、3D 视口角色实时展示卡 |
| **二次确认弹窗** | `centered-dialog` | 重生确认、购买扣费确认、提示 | 居中悬浮、阻断式半透明背景、主次按钮分明 |
| **任务与成就中心** | `progression-hub` | 每日任务、战令通行证里程碑 | 线性进度条、阶梯节点奖励、一键领取状态反馈 |
| **排行榜单** | `stat-leaderboard` | 积分榜、段位榜、连胜排行 | 滚动列表、前三名特殊皇冠/奖牌排版、自己名次固定置底 |
| **瞬态通知与 Toast** | `notification-alert` | 升级提醒、错误告警、系统通告 | 顶部/中上方弹出、自动渐隐销毁、不抢夺操作焦点 |
| **大转盘抽奖** | `wheel-spin` | 八分区概率转盘、每日免费轮盘 | 径向扇形布局、中间指针、匀减速物理回弹算法 |
| **卷轴开箱** | `vertical-reel-roll` | 盲盒、扭蛋、开蛋机滚动卷轴 | 竖向连续跑马灯、减速锁格动效、金光稀有度爆发 |
| **放置连点器** | `incremental-clicker` | 大点击主按钮、每秒产出数值 | 超大响应区、点击浮动缩放动效（Punch Scale） |
| **管理后台控制台** | `admin-control-panel` | 调试菜单、GM 指令面板、监控 | 紧凑信息流、可折叠分组、日志控制台面板 |

## 三、参考图还原工作流 (Reference Mockup Workflow)

若用户提供了参考原型或 UI 截图：
1. **参考图即为主契约 (Primary Specification)**：严格还原布局占比、Header 比例、卡片宽高比、列数间距（Gap）与边缘留白（Padding）；
2. **设计分辨率与根画布**：统一以 `1920 × 1080` 作为设计基准，根节点挂载 `UIScale`（Scale 为 1.0）；
3. **绝对与相对比例平衡**：外层容器使用 Scale 保证全屏铺满与居中，内层卡片与文字结合 Offset 保持精致比例与文字排版不被强行拉伸。

## 四、图标与视觉资产流

1. **禁止直接写死不可用的本地路径**；
2. **通用图标**：优先调用 `resolve_icon` 解析官方精选图标集；
3. **原创/项目专属图标**：
   - 在 Blender 中无头渲染透明背景的 2D 物品图标（PNG）；
   - 使用 Open Cloud 上传为云端 Decal，获得合法的 `rbxassetid://`；
   - 填入对应 `ImageLabel` / `ImageButton`。

---

## 五、项目工程规范与自适应保障

1. **模板唯一来源原则**：
   - 所有界面的持久化模板必须在 Studio **Edit 模式** 下存放在 `ReplicatedStorage.UI`（Folder）中；
   - 代码只克隆、绑定数据并驱动动效，禁止通过运行时代码拼接 UI。
2. **多端安全区避让**：
   - 移动端必须处理好 `DeviceSafeInsets`（全面屏刘海与下巴避让）；
   - 桌面端配置 `CoreUISafeInsets`；
   - 触控按钮尺寸：最小触控目标不低于 44×44 studs 对应像素，跳跃键与攻击键避开屏幕最边缘。
3. **3D 浮动文字 (BillboardGui) 规范**：
   - 必须开启 `TextScaled = true`；
   - 挂载的 `UIStroke` 强制设置 `StrokeSizingMode = ScaledSize`，杜绝固定像素边框在大距离缩小时吞食字体。
