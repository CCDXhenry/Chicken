# 多语言本地化规范

所有游戏内显示的需多语言支持的文本须遵循：
- 禁止在脚本中直接对UI组件设置`Text`。
- 静态文本直接在 Roblox Studio 内对UI组件设置 `Text` 并勾选 `AutoLocalize`。
- 动态文本必须在 `GameTexts.luau` 定义或由 Excel 导出的各个 `xxxData.luau` 以 `"_t"` 结尾的字段，UI组件不勾选 `AutoLocalize`，运行时对UI组件使用 `TranslationTool.CustomAutoLocalizeGui`。

所有游戏内显示的不需多语言支持的文本须遵循：
- 不勾选UI组件的 `AutoLocalize`。
- 可在脚本中直接对UI组件设置 `Text`。

GameTexts 定义规范

- `source` 文本必须为纯英文。
- 静态纯英文文本使用空 `key`，即 `key = ""`。
- 包含变量或动态拼接的文本必须定义唯一 `key`。
