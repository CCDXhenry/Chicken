# 网络权威、碰撞与高延迟

通用网络同步与权威校验原则，用于涉及移动、采集、战斗或预测的任务。

## 权威边界

- 服务端负责状态、伤害、奖励、产出和资格终审；客户端可立即播放本地预测表现，但上报必须只是请求。
- 服务端校验玩家身份、参与资格、当前状态、参数类型与有限数、空间边界、动作频率以及时间窗口。严禁只校验 typeof(number) 而接受 NaN/Infinity。
- 使用服务器时间表达跨端阶段终点，客户端由绝对结束时间计算倒计时。状态流使用运行标识与递增版本隔离乱序、重复和旧任务回调。
- 关键结算必须走可靠通信通道；避免无校验直接信任客户端参数。

## 碰撞与交互校验

- 拾取、交互和攻击范围以实际实体位置、角色躯干及缩放为依据，不以超大透明 Hitbox 或饰品/手脚的 Touched 作为唯一权威判据。
- 快速运动按需要采用跨帧扫掠或空间查询，补足单帧穿透；区分真实刚体阻挡、业务触发和纯视觉边界。
- 空间检测需校验请求发起时的距离与频率，不能直接相信客户端上报的位置，防止跨地图瞬移拾取或作弊。

## 表现平滑

- 延迟事件携带发生时间；以有界时间差推算当前状态，再平滑吸收视觉偏差。不要直接将画面重置到收到的历史位置。
- 平滑参数按帧时间计算，限制外推窗口，过滤过期、乱序与未来时间异常包。
- 视觉补偿和物理权威分离，不在观察端每帧强写由引擎复制的远端部件来对抗复制管线。
- 纯视觉表现位姿不得反过来参与服务端结算。

## 按需验证

用户要求运行测试时，覆盖正常网络、丢包/乱序、重复请求、角色重生和旧回调；关注双方看到的接触位置与权威结果。没有进行运行测试时，不报告“网络校验已通过”。
