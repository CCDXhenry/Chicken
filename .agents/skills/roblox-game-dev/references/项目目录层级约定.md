# Roblox Studio 项目目录层级约定：

- `ReplicatedStorage`：
  - `Core`：客户端需要用到的跨项目通用部分。
    - `Scripts`：客户端需要用到的跨项目通用代码，如 `UIAdapter`、`SoundTool`。
  - `BindableEvents`：客户端使用的 `BindableEvent`。
  - `Models`：动态创建的模型。
  - `RemoteEvents`：`RemoteEvent`。
  - `Scripts`：
    - `Client`：客户端脚本、`ModuleScript` 和动态添加的 `LocalScript`，如 `ClientGameInfo`、`UIManager`、各系统 `XXXManager`。
    - `Shared`：服务端与客户端共用的 `ModuleScript`，配置、多语言文本、网络协议等。
  - `Tools`：工具。
  - `UI`：动态创建的 UI。
- `ServerScriptService`：服务端默认运行的脚本，服务端入口，集中初始化 `ServerStorage` 内各模块。
- `ServerStorage`：
  - `Core`：客户端不需要用到的跨项目通用部分。
      - `Scripts`：客户端不需要用到的跨项目通用代码。
  - `BindableEvents`：服务端使用的 `BindableEvent`。
  - `Scripts`：服务端 `ModuleScript` 和动态添加的 `Script`，如 `ServerGameInfo`、各系统 `XXXManager`。
- `StarterPlayer`：
  - `StarterPlayerScripts`：客户端默认运行的 `LocalScript`，客户端入口，负责预加载资源及初始化客户端模块。
